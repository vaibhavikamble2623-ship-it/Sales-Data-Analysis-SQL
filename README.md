# Sales Data Analysis Using Oracle SQL

This project is a Sales Data Analysis project developed using Oracle SQL. It is designed to analyze sales transactions and generate useful business insights from customer, product, employee, category, and sales data.

The project uses a relational database structure with five main tables: Categories, Products, Customers, Employees, and Sales. These tables are connected using primary keys and foreign keys to maintain relationships between the data.

## Project Objective

The main objective of this project is to use SQL queries to analyze sales data and understand sales performance. The project focuses on identifying important information such as total sales, revenue, product performance, customer spending, employee performance, category-wise sales, and sales trends.

## Database Tables

### Categories
Stores product category information such as Electronics, Furniture, Clothing, Books, and Home Appliances.

### Products
Stores product details including product name, category, and price.

### Customers
Stores customer information including customer name, city, and state.

### Employees
Stores employee information including employee name, department, and salary.

### Sales
Stores sales transaction details including customer, product, employee, quantity, sale date, and discount.

## Revenue Calculation

The project calculates gross and net sales using product price, quantity, and discount.

Gross Sales:

Quantity × Product Price

Net Sales:

Gross Sales − Discount Amount

These calculations help understand the actual sales performance of each transaction.
